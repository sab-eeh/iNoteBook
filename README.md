# 📝 iNotebook - MERN Stack Application

## 📌 Project Overview
**iNotebook** is a full-stack **MERN** application designed for managing personal notes securely. Each user has their own private notes, which cannot be accessed by others. The app includes authentication features such as **login and sign-up**, ensuring data privacy.

## 🛠 Technologies Used
- **MongoDB** (Database for storing notes & user authentication)
- **Express.js** (Backend framework for API handling)
- **React.js** (Frontend UI development)
- **Node.js** (Server-side execution)
- **Mongoose** (ODM for MongoDB integration)
- **bcryptjs** (Password encryption)
- **jsonwebtoken** (User authentication & session management)
- **express-validator** (Validation for input fields)
- **cors** (Cross-Origin Resource Sharing)

## 🚀 Features
### ✅ Core Features
- 📝 **Create, Update & Delete Notes**
- 🔒 **User Authentication (Login & Sign-up)**
- 👤 **Private Notes - Each user can only see their own notes**
- 🔄 **Real-time updates** using API calls

## 📁 File Structure
```

│   │── src/

│   │── pages/             # Screens (Login, Signup, Notes)

│── README.md             # Project documentation
```
